# 探访报告模块 - 字段映射与页面原型


## 一、字段映射表（Excel -> 系统页面）

| Excel 原始列名 | 系统字段名 | 表单控件 |
| --- | --- | --- |
| Timestamp | 时间戳 `timestamp` | 自动生成 |
| Name of Staff/Volunteer 职员/志愿者姓名 | 报告人 `staffName` | 自动填入（当前用户） |
| Date of Visit 探访日期 | 探访日期 `dateOfVisit` | 日期选择器 |
| Time of Visit 探访时间 | 探访时间 `timeOfVisit` | 时间选择器 |
| Duration of Visit 探访时长 | 探访时长 `durationOfVisit` | 文本输入 |
| Location 地点 | 地点 `location` | 文本输入 |
| Name of Programme 项目名称 | 项目名称 `programmeName` | 文本输入 |
| Type of Visit 探访类型 | 探访类型 `typeOfVisit` | 下拉选择 |
| Name of Sangha 师父法名 | 僧人 `clientId + clientName` | 搜索选择器 |
| Purpose of Visit 探访目的 | 探访目的 `purposeOfVisit` | 文本输入 |
| What was done? 做了什么？ | 工作内容 `whatWasDone` | 多行文本 |
| What did you observe about the environment? 环境观察 | 环境观察 `environmentObservations` | 多行文本 |
| What did you observe about the Sangha? 僧众观察 | 僧众观察 `sanghaObservations` | 多行文本 |
| Any other observations? 其他观察 | 其他观察 `otherObservations` | 多行文本 |
| Personal thoughts and reflections 个人反思 | 个人反思 `personalReflections` | 多行文本 |
| Recommendations for next visit 下次建议 | 建议 `recommendations` | 多行文本 |
| Matters to highlight to Programme Team Lead 需向负责人汇报 | 需汇报事项 `mattersToHighlight` | 多行文本 |

> 权限说明：Social Worker 和志愿者均可提交探访报告；列表页中 SW 可查看全部，志愿者仅可查看自己提交的。

## 二、页面原型 - 探访报告列表页 `ReportListPage`

### 页面结构

- 顶部：系统标题 + 当前用户
- 左侧导航：工作台、僧人档案、个案管理、探访报告（当前）
- 操作按钮：`+ 提交新报告`
- 列表列：日期、报告人、僧人、类型、地点、时长、操作

### 列表示例

| 日期 | 报告人 | 僧人 | 类型 | 地点 | 时长 | 操作 |

## 三、页面原型 - 提交探访报告 `ReportFormPage`

### 区块 1：基本信息 / Basic Info

- 僧人 / Client *（搜索选择）
- 探访日期 / Date of Visit *
- 探访时间 / Time of Visit
- 探访时长 / Duration
- 地点 / Location
- 项目名称 / Programme
- 探访类型 / Type of Visit
- 探访目的 / Purpose

### 区块 2：观察记录 / Observations

- 做了什么？/ What was done?
- 环境观察 / Environment Observations
- 僧众观察 / Sangha Observations
- 其他观察 / Other Observations

### 区块 3：反思与建议 / Reflections

- 个人反思 / Personal Reflections
- 下次建议 / Recommendations
- 需向负责人汇报 / Matters to Highlight

提交按钮：`提交报告 / Submit`
